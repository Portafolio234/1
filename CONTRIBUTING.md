# Guía de Contribución

¡Gracias por interesarte en mejorar este proyecto! Como este es un portafolio personal, las contribuciones están orientadas principalmente a optimizaciones de rendimiento, corrección de bugs o sugerencias de diseño.

## 🛠️ Proceso de Desarrollo

1. **Bug Reports**: Si encuentras un error visual o funcional, abre un *Issue* describiendo los pasos para reproducirlo.
2. **Mejoras**: Si tienes una idea para optimizar los hooks de IA o las animaciones, ¡es bienvenida!
3. **Flujo de Git**:
   - Trabaja siempre en una rama descriptiva.
   - Asegúrate de que `npm run build` pase exitosamente antes de enviar cambios.

## 📜 Estándares de Código

Este proyecto utiliza **Vite** y **Tailwind CSS**.

- Mantén los componentes pequeños y modulares.
- Documenta cualquier nuevo *Custom Hook*.
- No subas archivos `.env` o credenciales personales.

¡Hagamos que el código sea cada vez mejor! 🚀
